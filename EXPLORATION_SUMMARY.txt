================================================================================
                         SYSTEM ARCHITECTURE
================================================================================

INPUT LAYER:
  ImageSource → TextureFramePool → Image Building (GPU/CPU/CPUAsync)

DETECTION LAYER:
  PoseLandmarker task with 3 running modes
  Output: PoseLandmarkerResult (normalized + world landmarks + masks)

ANNOTATION LAYER:
  PoseLandmarkerResultAnnotationController
  Thread-safe result handling with CloneTo()

VISUALIZATION LAYER:
  MultiPoseLandmarkListWithMaskAnnotation
  ├─ 33 landmarks rendered as circles
  ├─ 32 skeleton connections rendered as lines
  └─ Optional segmentation mask overlay

OUTPUT LAYER:
  Unity Canvas → Screen (via RawImage + Annotation rendering)

================================================================================
                          LANDMARK STRUCTURE
================================================================================

Total Landmarks: 33
Left Landmarks: 16 indices
Right Landmarks: 16 indices
Connections: 32 (limbs)

Landmark Groups:
  - Face: 0-10
  - Arms/Hands: 11-22
  - Torso/Hips: 23-28
  - Legs: 29-32

Each landmark contains:
  - Position (x, y, z)
  - Visibility score [0,1]
  - Presence score [0,1]
  - Name (optional)

================================================================================
                        CONFIGURATION OPTIONS
================================================================================

Running Modes:
  1. IMAGE: Single frame, synchronous
  2. VIDEO: Frame sequence with timestamps
  3. LIVE_STREAM: Continuous async (may drop frames)

Image Read Modes:
  1. GPU: Direct GPU copy (Android + OpenGL ES3)
  2. CPU: Synchronous CPU readback
  3. CPUAsync: Asynchronous GPU readback (default)

Model Variants:
  1. Lite: Fastest, least accurate
  2. Full: Balanced (default)
  3. Heavy: Slowest, most accurate

Confidence Thresholds (all default to 0.5):
  - minPoseDetectionConfidence
  - minPosePresenceConfidence
  - minTrackingConfidence

Options:
  - numPoses (default: 1)
  - outputSegmentationMasks (default: false)
  - Delegate: CPU or GPU

================================================================================
                        THREAD SAFETY MECHANISMS
================================================================================

Lock-based Synchronization:
  - _currentTargetLock object in PoseLandmarkerResultAnnotationController
  - Protects result cloning and mask reading
  - Release happens after UpdateCurrentTarget()

Stale Flag Pattern:
  - isStale flag indicates changed data
  - LateUpdate() checks flag on main thread
  - SyncNow() always runs on main thread only

Safe Data Copying:
  - CloneTo() method for safe result transfer
  - Segmentation masks cleared after reading
  - No shared mutable state between threads

================================================================================
                        MEMORY MANAGEMENT
================================================================================

Pre-allocation:
  - Results allocated via PoseLandmarkerResult.Alloc()
  - TextureFramePool pre-allocates 10 frame buffers
  - Reduces garbage collection overhead

Per-Frame Cleanup:
  - Segmentation masks explicitly disposed
  - DisposeAllMasks() called after each frame
  - Prevents GPU memory leaks

Resource Cleanup:
  - taskApi?.Close() on shutdown
  - _textureFramePool?.Dispose()
  - Annotation objects destroyed in OnDestroy()

================================================================================
                      PERFORMANCE CONSIDERATIONS
================================================================================

GPU Mode:
  - Only available on Android with OpenGL ES3
  - Fastest frame reading
  - Requires GpuResources initialization

CPUAsync Mode (Default):
  - Asynchronous GPU readback
  - Prevents frame drops
  - Best for performance

Segmentation Output:
  - Optional for performance
  - Requires GPU memory
  - Recommended disabled if not needed

Model Selection:
  - Lite: Best for performance
  - Full: Good balance
  - Heavy: Best accuracy
